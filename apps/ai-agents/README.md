# joola-ai-agents

Python FastAPI service implementing JOOLA's 7-agent LangGraph claim-processing pipeline.

```
intake -> shopify -> warrreg -> rules -> summary -> response
                                                 \
                                                  -> esc   (only if HUMAN_REVIEW_REQUIRED)
```

Only agent `06 response` calls an LLM (GPT-4o, with prompt-cached system prompt). Every other agent is pure logic + Supabase reads/writes.

## Endpoints

| Method | Path                                  | Purpose                                                                 |
| ------ | ------------------------------------- | ----------------------------------------------------------------------- |
| GET    | `/health`                             | liveness                                                                |
| POST   | `/pipeline/run`                       | run full 7-agent pipeline for a claim                                   |
| POST   | `/tools/lookup_order`                 | direct tool — query order by number or customer email                   |
| POST   | `/tools/check_warranty_registration`  | direct tool — NFC registration lookup                                   |
| POST   | `/tools/evaluate_eligibility`         | direct tool — pure delegation to `warranty_policy.evaluate`             |
| POST   | `/tools/create_claim`                 | direct tool — insert into `claims`, optionally kick off pipeline        |
| POST   | `/tools/escalate_to_human`            | direct tool — insert into `escalations` and bump claim status           |

All tool endpoints are designed to be called by the Fastify API in `apps/api`, which in turn forwards Vapi voice-tool requests during a live call.

## Setup

```bash
# Python 3.11+
cd apps/ai-agents

# Option A: uv (recommended)
uv sync                                       # picks up [tool.uv.sources] warranty-policy = path "../../packages/warranty-policy"

# Option B: pip
pip install -e ../../packages/warranty-policy # editable install of the workspace package
pip install -e .[dev]
```

Create `c:\Workspace\SaaS_CS_AIAgent_Team\.env.local` at the **repo root** with the variables from `.env.example`.

## Run

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

## Test

```bash
pytest
```

## Deploy (Railway)

- Service Root: `apps/ai-agents`
- Build: auto (Railway detects `pyproject.toml`)
- Start: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
- Env vars: set every variable from `.env.example` in Railway's UI.

> Railway must be told to install the workspace dependency. Easiest: commit a `requirements.txt` generated by `uv pip compile pyproject.toml -o requirements.txt`, or rely on the `uv.sources` table if Railway's builder honors it. In `pip`-only setups, add `pip install -e ../../packages/warranty-policy` to a `nixpacks.toml` install phase.
